## Colour freeze and ownership

Hold floating star to open the anchored menu: Auto team, visible coin colours, All colours/Freestyle, Next route. Tap White, Black or another colour once. A compact label under the star identifies the lock. It persists without waiting for a colour badge. Menu opening/selection disarms automatic shots; selecting a colour resumes AUTO pass-through and clears old target guidance. Captured results with an older colour key are discarded.

A colour lock limits final targets, while AUTO can select a better coin of that same colour after repositioning. A separately tapped individual coin remains an individual lock. Manual colour choice is explicit and can override a misidentified badge. Auto team restores badge-based ownership.

Visible assigned-team recognition takes precedence over leftover All mode. The assignment is cached across brief badge occlusion, including an All toggle, and the stored permissive override is cleared on confirmed assignment. Actual board loss or positively recognized freestyle clears the session cache. True freestyle and a fresh explicit All fallback with hidden legend still work.

The wrong black cluster ring was reproduced as a stale selected-target object, not a valid transfer route. Failed target matching now hides stale objects and releases explicitly ineligible selections, so a prior black selection cannot remain circled when current eligibility excludes it. Rendering independently resolves any displayed selected ring against current eligible detections.

## Queen first

Plain red queen classification requires predominantly red inner fill, rather than a red rim alone. Real queen sample had98.2% red inner coverage versus25.9–32.7% for five red/black opponent skins. Those patterned opponent discs are not queens.

The user's declared priority is applied when known assigned play has exactly one eligible own ordinary coin and exactly one verified queen: only the queen is a final target, with the last own coin retained as an obstacle/transfer. A previous lock on the last own coin no longer prevents queen guidance. QUEEN FIRST explains the intentional target change. Freestyle, unknown ownership, multiple ambiguous queens and red skins do not trigger it. Queen power/cover remains manual and is not a complete implementation of every carrom rule variant.

## Research and fresh references

[Running the Table / PickPocket, AAAI2006](https://fileadmin.cs.lth.se/ai/Proceedings/aaai06/09/AAAI06-156.pdf) motivates generating relevant shot classes, varying speed for different post-shot states and assessing uncertain outcomes. The bounded speed exploration here is an adaptation, not a full Monte Carlo game-tree player. [CarromTutor, IIT Bombay](https://www.cse.iitb.ac.in/~sri/papers/carromTutor-t4e2014.pdf) explicitly includes deflections, breaking clusters and positional strategies, and calibrates its simulator against expert shots. BitAim still needs that real-game power/spin calibration. Research notes are under test-results/agent-simulation/RESEARCH_AND_1606_REFERENCES.md.
