# v4.3 — manual aim focus, freestyle fallback and cluster opening

## Player-facing changes

- The game’s white dotted aiming guide is detected separately from BitAim’s cyan/green drawings. The planned striker line and contact circle turn green only after the observed direction aligns within 1.5 degrees in three increasing capture IDs. The overlay shows angular error while adjusting. This confirms direction agreement, not shot power or a guaranteed pot.
- Route changes immediately clear old green alignment, even when cycling within the same captured frame. Repeated or replayed frame IDs cannot create confirmation. Detector IDs remain increasing across capture-service restarts.
- Route choices now include a striker cushion followed by a coin combination. A bounded search tests up to eight geometric candidates per family and keeps up to three verified options; cluster opening has a separate bounded family. Holding the floating icon cycles numbered options for the selected coin.
- Cluster opening has a separate objective: verified first contact and movement of at least three discs in the nominal model, without a simulated scratch/opponent pot. It draws only the striker approach and first-contact marker, with a manual-power label. It never draws a false coin-to-pocket prediction and automatic shots do not execute this route type.
- Freestyle legends are recognized both near the avatars and just above the board, with either black/white order. Latest live capture live-colour-20261107-151207.png now identifies all 18 discs and gives a nominal direct pot route.
- Explicit “All colours • Freestyle” setting allows selection without any visible colour badge or legend. It persists across capture restarts. Turning it OFF restores conservative automatic team recognition. Changing this setting disarms automatic shots and clears previous guidance.
- Capture-aware messages distinguish a hidden/obscured board from capture being off. The YOU WIN screenshot colour-failure-20261107-151021.png is correctly rejected as an obscured board.
- Stationary coin and striker radii are stabilized with their positions/board bounds, preventing small width noise from invalidating the physical-state cache unnecessarily.

## Parallel independent review and fixes

Three sub-agents independently handled simulation, targeted testing and Android/UX review, using separate harness directories.

Simulation identified two genuine correctness defects: the former six-second cutoff accepted a later striker scratch (reproduced at 9.8667 seconds), and the physics cache ignored changed puck radii. The solver now searches the entire remaining displacement under its exponential-friction model, fails closed on exhausted event budget, hashes the complete physical state, and clears old validation flags on failure. In a repeated 3,000-world sparse synthetic sweep, 26,077 accepted routes had no late-continuation failures against the longer same-model reference. This is model consistency evidence, NOT measured game accuracy.

Independent targeted tests: 24 passed / 0 failed, including both freestyle legend orders, obscured legend rejection, explicit override, guide false positives, forward/backward guides, route-switch alignment invalidation, frame replay and detector restart recovery. Android review fixed API24 List.sort use for minSdk23, capture-aware picker wording and missing automation reset on unknown-team frames.
