# v4.2 — stable gold marker and optional automatic gestures

Includes the detection, route and model-score changes documented in V4.1.2_REPORT.md.

The user explicitly requested automatic striker movement and shooting, including online matches. This extends the original aim-only scope in GOALS_AND_TEST_PLAN.md.

## Stability

The former four-pixel quantized scene hash could invalidate gold calculations on rounding boundaries. GoldSceneLock compares actual disc, pocket and board movement against a retained scene, independently of horizontal striker movement. Tiny board-edge noise is frozen, and AUTO keeps its chosen target until it disappears, changes ownership, or the user chooses another coin. A saved target remains visible when its current route is unavailable.

## Optional move and shoot

- OFF on every service start. Explicit main-screen switch arms it; simply enabling Android's accessibility service does not arm shots. Floating icon tap stops it. A header identifies when automatic shots are armed.
- Android AccessibilityService dispatches input only when the active window belongs to com.miniclip.carrom and both gesture endpoints lie within that window. Android 7/API 24 or later is required for dispatch.
- Require eight stable intervals, a current model signature, a detected own turn, and at least 8/9 model stress tests before shooting. No input on a missing board, unknown ownership or opponent turn.
- Gold repositioning uses the estimated lower slider at board.bottom + 0.40 × board.width. Subsequent detection must verify the new striker position; otherwise the controller disarms. This mapping is inferred from supplied screenshots and is not device-calibrated.
- Pull opposite the initial route direction, then release. Pull distance is adjustable from 6–25% of board width, initially 12%. It is NOT a calibrated mapping from nominal launch speed to actual-game power.
- At most one shot before the turn resets; gesture failure/cancellation disarms. Only already-dispatched gestures can complete after a stop; future gestures are blocked.
- Singles, doubles and freestyle recognition are shared with normal guidance; optional gestures are not restricted to offline matches, per user preference.
